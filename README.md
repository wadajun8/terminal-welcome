# terminal-welcome

ターミナルを起動したときに表示するウェルカム画面。Claude と一問一答で段階的に設計している。

コンセプトは**「宇宙船の計器が起動する1秒」**。ドット絵のレーダーがフェードインし、実際のマシンの状態でゲージが埋まる間だけビームが回り、`▲ ALL SYSTEMS GO` が出たところで止まるまでを、毎回の起動の儀式にする。

## 決定事項

### フェーズ1：体験
- **起動したときの気分：高揚感・始動感**（「静かな集中」「状況把握」「遊び心」より、作業を始める勢いを優先）
- **演出の長さ：約1秒**。ただし**キーを押せば即スキップ**して最後の画面を出す。毎回待たされるストレスをなくすため

### フェーズ2：表示する情報
- 表示するのは **マーク・日付と時刻・起動シークエンス（計器）** だけ
- 不採用：
  - MISSION（作業の続き）と TODO：情報をどこから取るか（git の自動取得か、手書きのファイルか）を決めると管理の手間が出るため
  - 一言メモ：同じく管理の手間を増やさないため
  - 「ユーザー名-OS」のような名前の文字：ダサいため

### フェーズ3：世界観・配色
- **計器（B案）を骨組みに、サイバーパンク（A案）のネオン配色を合わせる**。グリッチ（ノイズで文字が崩れる演出）は、タイトルと最後の行にだけ使う
- 配色：**tron**（青一色の電子回路）。256色の番号で、枠 24、ゲージ 45、ラベルと CHECKING 31、NOMINAL 白 255（太字）、タイトルと GO 51、WARNING オレンジ 208、マーク 51
  - フェーズ4で7案（neon / synthwave / tron / matrix / akira / vapor / amber）を `demo/palettes.sh` で見比べて決めた。最初のネオン配色（枠 紫・ゲージ シアン・見出し マゼンタ）は `PALETTE=neon` で残してある
  - 青一色の中で WARNING を目立たせるため、警告だけ補色に近いオレンジにしている
- **ゲージには実際の値を出す**（飾りではなく、本当のセルフチェックにする）
  - CPU：`/proc/stat` を2回読んで使用率を計算
  - MEM：`/proc/meminfo`（MemTotal − MemAvailable）
  - DISK：`df -P /`
  - GPU：ゲージは VRAM 使用率、右側の文字は温度。`nvidia-smi` は遅いので、最初に裏で走らせて待ち時間を演出で隠す
  - BAT：残量と AC 電源の有無
  - 不採用：ROS 環境、Docker のコンテナ数
- **WARNING（赤）の初期しきい値**：DISK・MEM 90%以上、BAT 20%以下かつ AC 電源なし、GPU 85℃以上。WARNING があると最後の行が `▲ N WARNING(S)` になる

### フェーズ4：レイアウト
- 順番：**マークがフェードイン → ゲージが実際の値まで伸びる → 日付 → ALL SYSTEMS GO**
- 幅で切り替え（`tput cols` / `tput lines` で判定）
  - 77列以上：マークの右にゲージ
  - 45〜76列：マークの下にゲージ（高さが29行以上あるとき）
  - マークが入りきらないとき（33列以上・10行以上）：**マークを省いてゲージだけ**。幅が41列未満ならバーを短くして収める（最短4マス）
  - それ以外：1行の要約だけ（例：`▲ CPU 6%  MEM 22%  DISK 56%  GPU 56C  BAT 95% AC  10/30 14:12`）
  - 狭い画面でも文字だけにせずゲージを出したい、というフィードバックで「ゲージだけ」の段階を追加した。小さい画面ではマークを出さない（ミニロゴやアイコンは不採用）
- ゲージの演出は「もう少しゆっくり」というフィードバックで、0.07秒と比べたうえで、1マスあたり 0.05 秒に決めた（`welcome.sh` の `GAUGE_STEP`）。全体の演出は約1.6秒だが、キーを押せば約0.05秒で最後の画面になる
- 高速化：描画のたびに `$(c 51)` のようなサブシェルで色コードを作ると、全体で約900回起動して約0.5秒かかっていた。0〜255番の色コードを配列 `F` に最初に1回だけ作るように変えた
- **マーク：ドット絵のレーダー**（14行×33列）
  - 外周の円、内側の同心円2つ、点線の十字線の上を、ビームが時計回りに回る。ビームの後ろには濃い残像と、市松模様（ディザ）の薄い残像が付く。ビームが通過した直後のブリップ（4個）は**緑**に光り、暗い緑で少し残ってから消える（ユーザーの指定。レーダーの反応らしく、どの配色でも緑にしている）。ブリップは1ドット。止まったときは専用の絵にする：ビーム・残像・ブリップを消し、円と十字線だけの**左右対称の絵**にする（ユーザーの指定。非対称な絵や動きの名残が最後に残ると気になるため）（ユーザーの指定。形は `tools/gen_radar.py` の `J_DOTS`）
  - **ゲージが動いている間と、`ALL SYSTEMS GO` の文字が崩れている間だけ回り、文字がすべて出た瞬間に止まる**。キーを押すとその場で止まる
  - ドット絵として描く（ユーザーの指定）。なめらかに塗る処理はせず、円はミッドポイント円、線はブレゼンハムの直線で1ドット幅に描く。中心をドットの中央に置き、上下左右対称にしている。1周は16コマ（22.5°ずつ）。ドット絵の直線は角度が細かいほどガタつくため
  - 色（tron）：外周 45、内側の線と薄い残像 24、ビーム 51、濃い残像 31、ブリップ 46（反応した直後）と 28（暗く残る）。配色を変えても合うよう、`welcome.sh` の `MARK_TONES` で配色の色から割り当てている
  - 1文字の上下2ドットを、`▀` の文字色と背景色で別々の色にしている（`48;5;N` の背景色を使う）
  - **縦横比の補正**：「楕円になってる」というフィードバックで、`tools/gen_radar.py` の `ASPECT`（1ドットの縦÷横）で横方向を伸び縮みさせて描くようにした。フォント（Ubuntu Mono）の数値上は文字の高さが幅のちょうど2倍でドットは正方形になるはずだが、画面ではピクセル単位で丸められて比率がずれる。`demo/aspect.sh` で比率を変えた円を並べて見てもらい、**1.25** に決めた（文字の高さが幅の約2.5倍）。円はミッドポイント楕円で描く
    - 1.25 だと横に広がるので、横並びが80列に収まるよう、レーダーを半径15→13ドット（16行→14行、幅33列）に小さくした
    - 別の端末やフォントで使うときは、`demo/aspect.sh` で測り直して `ASPECT` を変え、`--bash` の出力を貼り直す
  - `tools/gen_radar.py` で全コマを作り、`welcome.sh` の `MARK_FRAMES` に貼っている。`--png` で全コマを画像にして確認できる
  - 一度は「止まったあとも減速しながら回す」にしたが、文字が出たのにマークだけ動いているのは間延びするので、文字と同時に止めることにした。プロンプトが出たあとも回し続ける案は、出力のスクロールで画面が崩れるため不採用
- **不採用にしたマーク**
  - Ubuntu ロゴ：最初の仮のマーク
  - 噛み合う2つの歯車（参考画像 `12122.png`）：ゲージが動く間だけ回る案。歯数（12/8 → 10/7 → 8/6）、なめらかに塗る多数決、中心をそろえた対称化、2つの間のすき間、歯を尖らせる、と改善を重ねたが、16行という解像度では歯の凹凸がどうしてもきれいに出ず、やめた。生成スクリプト `tools/gen_gears.py` と歯数の比較画像 `tools/teeth_compare.png` は記録として残している

### フェーズ5：`~/.bashrc` への組み込み（途中）
- **表示の頻度：PC を起動（再起動）して最初の1回だけフル演出、2回目以降は1行の要約だけ**（例：`▲ CPU 3%  MEM 16%  DISK 56%  GPU 50C  BAT 95%  10/30 15:02`）。起動の儀式と日常の作業を分け、何十回も開くたびに待たされないようにするため

## マシン環境（2026-10-30 時点）
- ノートPC：`BAT0` と `AC0` あり
- GPU：NVIDIA GeForce RTX 3050 Laptop（VRAM 4GB）
- 16コア、メモリ 14GiB、ディスク 787G
- シェルは bash。`tmux` はなし

| `demo/aspect.sh` | 端末の文字の縦横比を測り、レーダーが真円に見える `ASPECT` を選ぶ |
| `tools/gen_gears.py` | （不採用）歯車のマークを生成していたスクリプト |
| `12122.png` | （不採用）歯車のマークの参考画像。出どころが分からないため、リポジトリには含めない |
| `tools/teeth_compare.png` | （不採用）歯車の歯の数（10/7・8/6・8/5・6/4）の比較画像 |

| `demo/f_link_start.sh` | リンクスタート風の演出のデモ（16:9 の光のトンネル → 白い光 → 四角がフェードイン）。`welcome.sh` をもとにしている |
| `tools/gen_tunnel.py` | 光のトンネル（虹色の輪と白い光の筋）のコマを、窓に合わせた 16:9 の大きさで ANSI として生成する（numpy を使う）。デモが `~/.cache/terminal-welcome/` に保存して使い回す |
| `demo/palettes.sh` | `welcome.sh` の配色案（7案）を1つずつ表示して見比べる |

## 試し方
```bash
bash ~/terminal-welcome/welcome.sh          # 今のウィンドウの大きさで表示
COLUMNS=60 bash ~/terminal-welcome/welcome.sh   # 縦並びを試す
bash ~/terminal-welcome/demo/all.sh         # 世界観の候補を見比べる
bash ~/terminal-welcome/demo/palettes.sh    # 配色の候補を見比べる
PALETTE=tron bash ~/terminal-welcome/welcome.sh   # 配色を指定して演出つきで見る
```
色とアニメーションを見るには、普段のターミナルで実行する（Claude Code の `!` 経由だとうまく表示されない）。
